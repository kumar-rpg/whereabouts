# UI Colour Scheme

## Light Mode

| Role | Token | Hex |
|---|---|---|
| Page background | `--bg` | `#EDF1F7` — cool light blue-grey |
| Card surface | `--surface` | `#FFFFFF` — white |
| Alt surface | `--surface-alt` | `#F3F7FB` — faint blue tint |
| Border | `--border` | `#C6D2E0` |
| Subtle border | `--border-subtle` | `#DDE5EE` |
| Primary text | `--text-1` | `#0B1E30` — near-black navy |
| Secondary text | `--text-2` | `#476278` — slate |
| Muted text | `--text-3` | `#8AAABB` — light slate |
| Accent (primary) | `--accent` | `#0B9868` — emerald green |
| Accent background | `--accent-bg` | `#DDF3EB` |
| Danger | `--danger` | `#DC2626` — red |

## Dark Mode

| Accent | `--accent` | `#12C98C` — brighter emerald |

## Typography

| Role | Font |
|---|---|
| Display / headings | Barlow |
| Body | DM Sans |
| Monospace / IDs | JetBrains Mono |

The overall palette is a **deep navy + emerald green** scheme — professional and clean, with distinct semantic colours per activity type.
